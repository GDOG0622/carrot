# 🥕 兔子不吃胡萝卜（carrot）

一个 SillyTavern 第三方扩展：给聊天加一个悬浮的「胡萝卜」快捷输入面板，把手机聊天软件那一套（气泡、图片、语音条、转账、表情包、链接卡片、主动消息、推送通知）搬进酒馆。

前端扩展 + 可选的酒馆后端 plugin 两部分组成。只装前端也能用大部分功能；装上后端可以额外获得链接解析、图片中转、语音转文字、Web Push、角色主动发消息等能力。

> 当前版本：前端 `8.0.59` / 后端 `8.0.53`

---

## ✨ 主要功能

### 快捷输入面板

屏幕上常驻一个可拖动的胡萝卜浮标，点开就是输入面板：

- **纯文本 / 图片 / 视频 / 音乐 / 钱包** 五种插入类型，一键生成固定格式的文本 token，塞进酒馆输入框
- **Emoji 选择器** 与**自定义表情包**（按分类管理，消息里的 `[描述]` 会自动替换成对应图片）
- **BUNNY 模式**：把当前输入包装成元层指令
- **语音输入**：录音直接转成文字（需要后端 + 自备语音识别 key）
- **本地图片上传**：图片直接进消息，不用先找图床
- **撤回**：一键生成撤回提示

### 美化渲染

把 AI 输出的纯文本按约定格式渲染成聊天界面，而不是一大段小说体。当前支持的写法：

| 写法 | 效果 |
|------|------|
| `『时间 \| 文本』` | 时间戳分割线 |
| `"文本"` / `“文本”` | 对话气泡（自动区分 user / char 方向） |
| `=标题\|正文=` | 语音条气泡 |
| `[标题\|数值\|说明]` | 转账 / 超次元气泡 |
| `+文本+` | 系统提示行 |
| `-文本-` | 撤回提示行 |
| `[描述]` | 替换成你自己的表情包图片 |
| `[描述.jpg]` | 按关键词自动配图（需自备 Unsplash key） |

同时兼容酒馆原生的 markdown / HTML 渲染，加粗、斜体、代码块、`<details>` 都照常工作；角色卡里把正文包一层 `<content>` 之类的自定义标签也能正确识别。

内置 `iOS` 和 `带头像透明` 两套气泡预设，可以新建自己的预设。

### 外观

- **主题**：高亮色、面板背景、功能栏背景、字体颜色
- **头像 / 头像框**：多套配置随时切换
- **QQ 人**：导入形象图集合，用 `<!--描述.qqr-->` 引用；浮标可以自动跟随聊天里最新出现的那张
- **全局字体**：支持 `@import` 的字体 CSS 和 `.woff2 / .woff / .ttf / .otf` 直链，单条添加或批量粘贴；可单独覆盖消息区的字号、粗细、行间距、段间距、字间距
- **拼豆挂件**：在扩展内画一张像素拼豆图，熨烫定型后挂在消息气泡角上，位置 / 大小 / 旋转 / 动效都能调，半透明的豆子会做成磨砂玻璃效果

### 通知

- 生成成功 / 失败分别播放自定义提示音
- 页面在后台时弹系统通知，文案可自定义
- 后台保活，切到后台也能出声
- **Web Push**：浏览器被杀掉也能收到（需要 HTTPS 域名 + 后端；iOS 需 16.4+ 并「添加到主屏幕」后开启）
- **Termux 本地通知**：原生 Termux 运行酒馆，并在同一台手机用 `localhost`、`127.0.0.1` 或 `[::1]` 打开时，后端通知自动使用安卓本地通道，不经过 Google；远程访问继续使用 Web Push。

#### Termux 本地通知准备

1. **Google Play 版 Termux 2026.02.11 及以上已内置通知支持，无需额外安装 App**（[官方说明](https://github.com/termux-play-store#updates)）；缺少 `termux-notification` 命令时请更新 Termux 及其软件包。GitHub/F-Droid 版则需安装与 Termux **相同来源、签名兼容**的 [Termux:API 应用](https://github.com/termux/termux-api)，并执行 `pkg install termux-api`。
2. 在安卓设置中允许 Termux（Google Play 版）或 Termux:API（其他版本）显示通知，并允许 Termux 在后台运行。
3. 更新前端、同步后端并重启酒馆进程；从本机 `http://127.0.0.1:8000`（端口按实际配置）打开酒馆，在通知设置开启“后端通知”，点击“测试 Termux 本地通知”。原来已开启后端推送的页面会在启动时尝试自动迁移本浏览器的旧订阅。

本地通知不需要浏览器推送权限、HTTPS 或 Google 网络。按钮显示“已调用”仅表示命令执行成功，仍需确认安卓实际显示通知；未显示时检查通知权限和系统通知渠道。缺少依赖或调用失败会提示原因，不会自动回退到 Google。

仅识别原生 Termux 和本机回环地址；局域网地址、域名、反向代理及 proot 容器不自动切换。关闭本地通知后，后端主动消息也不再向本机通知；其他设备的 Web Push 订阅保留。酒馆进程必须保持运行；普通聊天仍依赖页面收到生成完成事件，只有后端主动消息可独立于页面触发通知。模型接口本身是否需要代理与通知通道无关。

### 链接与图片（需要后端）

- **链接卡片**：消息里的网址自动抓标题 / 摘要 / 封面，渲染成卡片；抓不到时可选配 Jina Reader 兜底
- **封面转发给视觉模型**（可选）
- **多图堆叠卡**：多张图叠成一摞，可拖拽翻页、点开看大图
- **图床代理**：catbox 类链接自动改走后端代理，前端不直连；后端所在机器如果也连不上，可配置出站代理或自建 Cloudflare Worker 中转（源码在 `plugin/relay-worker.js`，附部署步骤）

### 角色主动发消息（需要后端）

给某个角色配一条规则（多久检查一次、按什么概率触发），后端到点自己发起生成，配合 Web Push 就能收到"角色主动找你"的推送。提示词模板可以自己改。

### 配置备份

设置面板的「同步」页可以把全部配置导出成 JSON 备份 / 分享，也能导回来，兼容旧版本的备份格式。

## 📦 安装

### 1. 前端扩展

酒馆里 **扩展 → 安装扩展**，填入本仓库地址：

```
https://github.com/GDOG0622/carrot
```

装完刷新页面，屏幕上出现胡萝卜浮标就成功了。

### 2. 后端 plugin（可选，但推荐）

链接解析、图片代理、语音转文字、Web Push、主动消息这几项需要后端。安装脚本会自动定位酒馆根目录、把 `config.yaml` 的 `enableServerPlugins` 改成 `true`、把 `plugin/` 复制到 `<酒馆根目录>/plugins/carrot` 并装依赖。

Windows：

```bash
plugin\install\install.cmd
```

Linux / macOS / Termux：

```bash
bash plugin/install/install.sh
```

**然后必须重启酒馆的 node 进程**（不是刷新网页）。重启完回到扩展设置的「API」页，看到绿色「已启用」就好了。

卸载脚本在同目录下的 `uninstall.cmd` / `uninstall.sh`。

> 用 pm2 或 systemd 管理酒馆进程的话，以后升级 carrot 可以在设置里点「同步后端」一键完成，不用手动重启。

## 🔑 需要自己准备的 key（全部可选）

扩展不内置任何 key，也不会把你的 key 发到除对应官方 API 以外的任何地方。以下功能按需自备：

| 功能 | 需要的东西 | 说明 |
|------|-----------|------|
| `[描述.jpg]` 自动配图 | Unsplash Access Key | 免费申请 |
| 语音转文字 | 硅基流动 key 或 Groq key | 都有免费额度 |
| 链接解析兜底 | Jina Reader key | 可选，只在正常抓取失败时才调用；支持多 key 轮换 |
| 图床中转 | Cloudflare Workers 账号 | 可选，仅在服务器直连图床失败时需要 |

填入位置：扩展设置抽屉 →「API」页。

photo-stack.js       多图堆叠卡

proactive.js         主动消息设置面板
setting/             主题 / 头像

## ⚠️ 说明

- 本扩展只在 SillyTavern 上测试，不保证在其他前端可用。
- 美化渲染依赖 AI 按上面的格式输出，具体格式约定请写进你的角色卡或预设。
- 后端 plugin 会在酒馆服务器上开放 `/api/plugins/carrot/*` 路由；请勿把没有鉴权的酒馆直接暴露在公网。
